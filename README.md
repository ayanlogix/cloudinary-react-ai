# Cloudinary AI React App

MLH Global Hack Week GenAI 2025 - Cloudinary + React Challenge

## Features
- React 18 with Babel standalone
- 10 AI-powered transformations (background removal, cartoonify, art filters)
- Real-time before/after preview
- Works with any Cloudinary account

## AI Features Used
- Background Removal
- Cartoonify
- Artistic Filters (Athena, Hokusai)
- Image Enhancement and Upscaling
- Restoration
